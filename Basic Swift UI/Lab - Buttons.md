# Buttons Lab Requirements - Due Sep 11, 2026
## Instructions:
For this lab we want you get some practice making buttons
- And we also want you to be able to use some creativity
- So as long as you complete the requirements, you can make your buttons look as crazy, or big, or weird as you’d like
- Requirements for the lab:
- Create at least 10 buttons all with something unique about each one
- At least one button has to cause a visible change on the screen
- At least one button has to use an icon or image instead of text
- At least one button has to be disabled (sometimes)
