# Stack Views 2 Lab Requirements - Due Sep 14, 2026

Complete each of the following exercises.

When finished, have an instructor sign off on your work.

## Instructions

In the "About the Developer" page you built for your Text Views lab, use Stack Views to make the following improvements to your about the developer page:

- Add a colored background to the whole screen using a Shape
- Give a different color background to a single element on screen using another Shape
- Add section headers to each piece of text. Section headers should be aligned to the leading edge of the screen and in a large, bold font.
- Add a default spacing for all views in at least one VStack.
